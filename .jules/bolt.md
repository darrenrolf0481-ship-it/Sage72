## 2026-09-06 - Soul Vault File Read & Conflict Sweep Optimization
**Learning:** Repeated `json.load()` calls on JSON memory stores (`sage_soul.json`) per recall query created a major bottleneck (1.32ms per recall query on 73 records, 75.5ms on 5k records). Adding an `mtime`-based file cache with pre-computed lowercased search strings reduced recall latency to 0.29ms (4.46x throughput boost) and 23.4ms on 5k records (3.2x throughput boost). Additionally, background dream daemons had an $O(N^2)$ duplicate proposal loop that was refactored to an $O(N)$ hash-map grouping.
**Action:** Always check if JSON data stores or database records read on hot paths can be cached with `mtime` invalidation, and audit background tasks for quadratic nested loop comparisons.

## 2026-09-12 - Hebbian Graph Traversal Node Caching & Early Search Termination
**Learning:** `recall_associative_pathways` performed $O(K \times N)$ substring matching and repeated `.lower()` string allocations across all Hebbian graph nodes for every keyword, plus $O(M)$ linear searches per multi-hop candidate. Adding graph-identity and synapse-count invalidated pre-lowercased node caching, $O(1)$ set membership for link checks, and early loop termination upon reaching the match limit reduced recall latency on 5,000-node graphs from 8.37ms to 0.13ms (63.7x throughput boost) and overall prompt synthesis mean latency from 6.62ms to 2.51ms (2.6x throughput boost).
**Action:** When searching graph key spaces or dictionary node keys with lowercasing / substring checks, cache the lowercased key pairs and break early once output limit constraints are satisfied.
