## 2026-09-06 - Soul Vault File Read & Conflict Sweep Optimization
**Learning:** Repeated `json.load()` calls on JSON memory stores (`sage_soul.json`) per recall query created a major bottleneck (1.32ms per recall query on 73 records, 75.5ms on 5k records). Adding an `mtime`-based file cache with pre-computed lowercased search strings reduced recall latency to 0.29ms (4.46x throughput boost) and 23.4ms on 5k records (3.2x throughput boost). Additionally, background dream daemons had an $O(N^2)$ duplicate proposal loop that was refactored to an $O(N)$ hash-map grouping.
**Action:** Always check if JSON data stores or database records read on hot paths can be cached with `mtime` invalidation, and audit background tasks for quadratic nested loop comparisons.

## 2026-09-09 - Hebbian Graph Multi-Hop Associative Recall Optimization
**Learning:** In `recall_associative_pathways`, calling `node.lower()` on every node per query keyword created massive redundant string overhead (7.15ms per recall query). Adding `get_lowercased_nodes()` caching to `AssociativeMemory` (invalidated on graph mutation), skipping already-visited nodes prior to substring evaluation, using $O(1)$ set collision checks for multi-hop links, and returning early when `limit` matches are reached cut `recall_associative_pathways` latency from 7.15ms to 0.36ms (19.4x speedup) and doubled overall memory context prompt synthesis throughput from 145 QPS to 303 QPS (3.30ms latency).
**Action:** Cache pre-lowercased string tuples on graph/dictionary keys, place set/visited membership checks before expensive string operations, and early exit when limit targets are fulfilled.
