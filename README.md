## Run Locally

**Prerequisites:** Node.js, Python 3

1. Install frontend dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the frontend:
   `npm run dev`
4. Run the backend:
   `python3 server.py`
